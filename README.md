## Проект контроллера управления установками систем вентиляции и отопления

# 1. Общее описание

__Проект:__  __HVAC_Controller__

__Цель проекта:__ Разработка контроллера управления наиболее распространенными 
		вариантами ситем вентиляции и отопления. 

__Область применения:__ Управление системами вентиляции и отопления.

__Аппаратная платформа:__  Разработанный контроллер управления HVAC_Controller на базе микроконтроллера stm32f101RCT6
- Цифровые входы:		- 4 шт
- Релейные выходы: 		- 4 шт
- Аналоговые входы 0-10В: 	- 3 шт
- Аналоговые выходы 0-10В:	- 3 шт
- Порт Modbus Master: 		- 1 шт			
- Порт Modbus Slave:		- 1 шт

__Программное окружение:__  CubeIDE 1.7.0, FreeRTOS v7.4.0

## Архитектура ПО:
1. FreeRTOS
   1. Задачи:
      - Start_ST7789_Task - работа с дисплеем ST7789 RGB 240x240
      - Start_EC11- работа с энкодером EC-11
      - StartAlgoritm - алгоритм системы управления
      - StartUSART_1- работа с портом UART1 Slave
      - StartUSART_2- работа с портом UART2 Master

   2. Очереди:
      - queueTFT- очередь сообщений в дисплей
      - queueTimer - очередь статусов в экран от таймера

   3. Таймер:
      - UpdateValueTimer_Fun - тймер обновлений экрана

2. HAL - Управление переферией микроконтроллера
	

3. Библиотека ST7789 - работа с экраном
	- ST7789.c
	- fonts.c

## Описание модулей и функций
	- main.c - Основной модуль
	- freertos.c - инициализация и обработка задач FreeRTOS
	- menu.c - Работа с меню дисплея
	- Flash.c - Содержит функции для работы со Flash памятью
	- EC11.c - функции работы с енкодером ЕС11
	- digital_bloks.c - библиотека цифровых модулей языка FBD
	- analog_bloks.c - - библиотека аналоговых модулей языка FBD
	- utils.c - вспомогательные функции
	- logo.c - определение графики
	- ST7789.c - библиотека функций работы с дисплеем ST7789
	- fonts.c - определение шрифтов
	- stm32f1xx_it.c - обработчики прерываний 

## Настройка и управление	
- Управление работой микроконтроллера осуществляется  посредством энкодера и дисплея расположенных на панели 
  контроллера согласно инструкции "Контроллер_Управления.pdf"

## Электрические подключения
- Электрические подслючения осуществляются при выключенном питании, после выбора типа системы HVAC1 ... HVAC5
согласно выбраной схеме и инструкции "Контроллер_Управления.pdf"
